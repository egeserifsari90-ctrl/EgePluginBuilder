# EgePluginBuilder

Mobil uyumlu Türkçe arayüzden genel web eklentisi başlangıç projeleri oluşturur.

## İşlevler
- Temel, popup ve içerik betiği şablonları
- Proje adı, kimliği ve açıklama doğrulaması
- README ve MIT lisans dosyası üretimi
- Dosya listesi ve kod önizlemesi
- ZIP indirme

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` seçin.

## Önemli
Bu araç genel amaçlı başlangıç dosyaları oluşturur. Üretilen `manifest.json` evrensel veya tarayıcıya özel geçerli manifest değildir. Chrome, Firefox, CapCut veya başka bir platformla gerçek entegrasyon için ilgili platformun resmî manifest şeması, API'leri ve izinleri gerekir. Araç kullanıcı parolası veya token istemez.
